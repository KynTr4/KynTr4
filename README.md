Most of it runs local-first — ComfyUI, Ollama and Python tooling on my own hardware, with SQLite and Parquet as the source of truth.

## What I'm building

- **[pedigreeall-ai](https://github.com/KynTr4/pedigreeall-ai)** — an open-source prediction platform for Turkish horse racing: automated endpoint discovery and collection, a normalized SQLite warehouse, feature engineering, a model comparison across XGBoost / CatBoost / LightGBM, SHAP explainability, and a read-only FastAPI dashboard.
- **Local AI on real hardware** — ComfyUI workflows and Ollama-backed tooling for image and video generation, wired into Python scripts and FFmpeg exports so output lands as usable files instead of demos.
- **Small tools, real use** — TypeScript and shell utilities that remove one annoying step from a daily workflow. Documented even when they break.

## How I build

- **Prototype first, polish second.** A working end-to-end path is worth more than a perfect component.
- **Local-first by default.** Data stays in SQLite and Parquet; models run on my machine before they run anywhere else.
- **Evidence over vibes.** Features and models get evaluated and monitored — "it looked good in the notebook" is not a result.
- **Write it down.** Every experiment keeps a README. The failed ones matter most.
