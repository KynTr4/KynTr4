## ⚡ Vibecoding Principles

- **Ugly first, working second.** Ship a prototype in hours, not weeks.
- **Local-first.** Run models and tools on your own machine, not just APIs.
- **Visible experiments.** If I broke it, I documented how.
- **Iterate forever.** Nothing is ever truly “done,” just ready for the next version.
